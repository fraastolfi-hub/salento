# Salento.it — bozza homepage

Bozza HTML della nuova homepage di Salento.it (novembre 2026).

- `index.html`: pagina unica, autonoma (CSS e JS inline). Si apre direttamente nel browser.
- Logo e palette dal brand manual Area38. Tono di voce "L'amico del posto".
- Quiz matchmaker funzionante: logica nello `<script>`, dati nell'oggetto `CERVELLO`.
- I dati di marine e strutture sono **segnaposto**: vanno sostituiti con il JSON del cervello.
- Il punteggio delle marine non usa mai commissione o conversione; la conversione ordina solo le strutture.
